# 卡卡颂 美术规格（spec）

> 方向：**1 春日沙盘**（开工拍板，`decisions/kickoff.json`），风格参考图 `~/projects/pipeline/games/carcassonne/assets/kickoff-1-spring.png`、`kickoff-1-spring-topdown.png`。
> 暂存目录：`~/projects/pipeline/games/carcassonne/art/`。定稿在 `art/out/final/`，目录结构就是将来的 `apps/web/public/art/`。
> 不用原版卡卡颂的美术和商标。所有数字、分数、文字都由界面用代码画，图里没有字。

## 1. 风格

- **视角**：地块和地图一律**正俯视**（从正上方看），房子、塔、修道院、树可以略带一点立体感，但不越出地块边界。
- **光照**：明亮晴天，柔和的正上方光；部件（房子、树等）统一是左上来光的小立体感。地块里的部件**不跟着地块旋转**：地块的每个旋转方向单独合成一张图（见 2.1），所以无论地块怎么转，房子都是正的，光都从左上来。
- **描边**：部件有 1px 深色描边（PixelLab 部件自带）；城墙外缘 1px 深灰 `#3a3a40`，路边 1px 棕 `#8a6a3e`。
- **像素密度**：地块原图 64×64，1 个原图像素 = 屏幕 1/2/3 个像素（整数倍）。部件按 64px 地块的比例出（房子约 12–16px、树约 12–16px、修道院约 36–40px、小人约 18×22px）。
- **调色板**（主色）：

| 用途 | HEX |
|---|---|
| 草地 亮 / 中 / 暗 | `#8fd14f` / `#5fae3c` / `#3f7f2c` |
| 城墙（灰石）高光 / 主色 / 暗面 / 外缘 | `#e4e1d8` / `#c9c6bc` / `#85827a` / `#3a3a40` |
| 城内地面（暖砂石板） | `#d6bc8c`，石缝深 30–34 |
| 圆塔（城墙上） | 奶白石 + 灰顶（PixelLab 部件） |
| 屋顶 陶红 | `#c4523a` / `#9a3b2a` |
| 道路 路面 / 亮 / 暗 / 路边 | `#e3c98a` / `#efdaa2` / `#c4a666` / `#8a6a3e` |
| 盾徽 蓝 / 金边 | `#2f5fb8` / `#e8c24a` |
| 牌桌（白天）石板 | `#b9b3a6` 一带 |
| 牌桌（夜间）石板 | `#2b2f3c` 一带 |

- **玩家颜色**（小人和界面上的名牌用同一套；避开草地绿和道路土黄）：

| 颜色 | key | 小人主色 | 界面用色（名牌、高亮） |
|---|---|---|---|
| 红 | red | `#e0473c` | `#e0473c` |
| 蓝 | blue | `#3b74e0` | `#3b74e0` |
| 紫 | purple | `#9b55d6` | `#9b55d6` |
| 白 | white | `#f3efe6` | `#f3efe6`（白天主题下名牌加深色描边） |
| 黑 | black | `#2c2c36` | `#2c2c36`（夜间主题下名牌加浅色描边） |

  小人图本身都带 1px 深色描边，白色和黑色小人另有一圈对比描边，草地、城内、道路上都分得清。

## 2. 素材清单

路径都是相对 `apps/web/public/art/`（暂存时是 `art/out/final/`）。「显示」指界面上的整数倍。

### 2.1 地块（核心）

| 文件 | 原始尺寸 | 显示 | 透明 | 帧 | 白天/夜间 | 用途 |
|---|---|---|---|---|---|---|
| `tiles/tile-<种类>-<r>.png`（种类 A–X，r = 0/1/2/3） | 64×64 | 1×（64）、2×（128）、3× | 不透明 | 1 | 共用一套 | 地图上的地块。**r = 顺时针转了 r 个 90°**，界面**直接换图**，不要用 CSS 旋转（部件和光影要正着）。 |
| `tiles/tile-<种类>.png` | 64×64 | 同上 | 不透明 | 1 | 共用 | 等于 `tile-<种类>-0.png`，未旋转朝向（和规则书 2.2 表一致），给规则说明、教程、图鉴用 |
| `tiles32/tile-<种类>-<r>.png` | 32×32 | 1×（32）、3×（96，可选） | 不透明 | 1 | 共用 | 缩小版，地图缩到「全图」时用（格子 ≤ 48px 时换这套） |
| `tiles/anchors.json` | — | — | — | — | — | 每种地块（未旋转）各段的**小人落点建议**和盾徽位置，比例坐标 0–1（x 向右、y 向下）。开发 agent 可以照抄进 `data/tiles.json` 再微调。旋转后坐标 (x, y) → (1 − y, x)（顺时针一次）。 |
| `tiles/tile-back.png` | 64×64 | 1×、2× | 不透明 | 1 | 共用 | 地块背面：牌堆、「剩余 N 块」旁边的图标（N 由代码叠） |

- **未旋转朝向**和规则书 2.2 完全一致（北上、东右）：比如 D 是北边城市、东西一条路；起始地块就是 `tile-D-0.png`。
- **边的统一画法**（任意两块合法相接时接缝对得上，`seams.py` 检查过）：
  - 道路：从边的**正中点**出入，路面宽 8px（x 或 y 在 28–35），两侧各 1px 路边。
  - 城市边：**整条边都是城内**（城墙画在城区和草地的分界上，不画在地块边上）；城内地面、草地按全局 64px 周期贴纹理，所以跨地块连续。
  - 草地边：纯草地，地块边缘 1px 内没有部件。
- **anchors.json 结构**（未旋转、比例坐标）：`{ "D": { "cities": [{"edges":"N","spot":[x,y]}], "roads": [{"road":["E","W"],"spot":[x,y]}], "fields": [{"ports":["E0","W1"],"spot":[x,y]}], "monastery": [x,y] 或 null, "shields": [[x,y]] } }`。`cities`、`fields` 的顺序和规则书 2.2 表一致（fields 按端口列表对上）。落点避开了城墙、路边、修道院、盾徽和树；城里的落点可能压在屋顶上，小人画在最上层就行。
- 每种地块要一眼分清：城市（城墙 + 房子）、盾徽（蓝底白斜纹金边小盾，正着放）、道路、路尽头的**村庄/路口**（三岔/四岔路中心的小村广场：石井）、修道院（中心的红顶十字教堂加小花园）、草地（树和灌木）。H、I 两段城市之间是一片草地，看得出是两段。
- 地块之间的分隔线（1px 半透明深色网格）由界面画，图里没有。

## 3. 牌桌上的尺寸（1440×790 估算）

- 牌桌区域（去掉右侧 300px 侧栏、上下名牌和操作条）约 1100×640。
- 72 块拼出的地图一般 10–14 格宽、8–12 格高（最极端约 15×15，拉长条时可能 20×6）。
- 默认缩放 64px/格（1×）：14×10 格 = 896×640，刚好放下中等大小的地图；地图大了拖动。
- 「全图」：格子算出来 ≤ 48px 时换 `tiles32` 用 32px（15×15 = 480，任何地图都能放下）；手机竖屏（约 390 宽）全图也用 32px。
- 拿着地块时手上的那块显示 2×（128px），四个旋转方向的小预览用 32px 版。
- 放大看细节：128px（2×）。所有显示都是整数倍，`image-rendering: pixelated`。

## 4. 要用代码画的

- 所有数字和文字：分数、「+N」、剩余地块数、剩余小人数、名次、玩家名。
- 地块间网格线、合法空位高亮（也可以用 `ui/slot-*.png`）、被结算区域的描边高亮。
- 小人飞回头像的位移、分数飘字。
